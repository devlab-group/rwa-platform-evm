# EIP-712 canonical type strings

These strings are the single source of truth for the Solidity contracts, the Go
signer, the Go server, and the TS client. They MUST match byte-for-byte.

## Domain

```
name:              "RWA-Supply-Attestation"
version:           "1"
chainId:           <current chain id>
verifyingContract: <SupplyController address>
```

`EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)`

## MintAttestation

Canonical type string (used for the type hash):

```
MintAttestation(address auditor,bytes32 profileDigest,bytes32 recordKey,bytes32 metadataDigest,uint256 amount,uint256 nonce,uint64 validUntil,address vault)
```

`MINT_ATTESTATION_TYPEHASH = keccak256(<string above>)`
= `0x` (regenerated by `shared/vectors/gen.mjs`; see mint-eip712.json)

Field order (must not change):
1. `address auditor`
2. `bytes32 profileDigest`
3. `bytes32 recordKey`
4. `bytes32 metadataDigest`
5. `uint256 amount`
6. `uint256 nonce`
7. `uint64  validUntil`
8. `address vault`

## BurnAttestation

```
BurnAttestation(address auditor,bytes32 profileDigest,bytes32 operationId,bytes32 metadataDigest,uint256 amount,uint256 nonce,uint64 validUntil,address vault)
```

`BURN_ATTESTATION_TYPEHASH = keccak256(<string above>)`

Field order:
1. `address auditor`
2. `bytes32 profileDigest`
3. `bytes32 operationId`
4. `bytes32 metadataDigest`
5. `uint256 amount`
6. `uint256 nonce`
7. `uint64  validUntil`
8. `address vault`

## Digest construction

```
digest = keccak256(0x1901 ‖ domainSeparator ‖ hashStruct(message))
domainSeparator = keccak256(abi.encode(
    keccak256("EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)"),
    keccak256("RWA-Supply-Attestation"),
    keccak256("1"),
    chainId,
    verifyingContract))
hashStruct(m) = keccak256(abi.encode(TYPEHASH, m.field1, ..., m.fieldN))
```

`uint64 validUntil` is ABI-encoded as a full 32-byte word (left-padded).

## Definitions

- `recordKey   = keccak256(bytes(recordId))` — unique per project mint.
- `operationId` — unique per de-tokenization event (server-generated random bytes32).
- `metadataDigest` / `profileDigest` — **SHA-256** of RFC 8785 canonical bytes (NOT keccak).
- `nonce` — server-generated random 256-bit value; shared namespace across mint & burn.
- `validUntil` — mandatory unix seconds; SHOULD be ≤ 30 days after package creation.

Note: profileDigest/metadataDigest use SHA-256 (per IPFS raw/sha2-256 CID convention);
only the EIP-712 struct/domain hashing uses keccak256.
